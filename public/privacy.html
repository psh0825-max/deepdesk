개인정보처리방침

1. 수집 항목과 목적

  • 이메일 주소 — 리포트 발송, 주문 관련 안내
  • 주문 내용(조사 주제·요구사항) — 리서치 수행
  • 결제 정보 — 카드 정보는 저장하지 않습니다. 웹사이트 결제는 결제대행사(토스페이먼츠)가, 모바일 앱 결제는 Google Play(Google LLC)·App Store(Apple Inc.) 인앱 결제가 처리합니다. 서비스는 주문번호, 결제 금액, 결제대행사 또는 스토어가 발급한 거래 식별자(구매 토큰은 해시로만)만 보관합니다.
  • 자동 수집 항목 — 앱과 웹사이트는 광고 식별자, 분석 SDK, 위치 정보를 사용하지 않습니다. 서버 접속 로그(IP, 시각)는 보안 목적으로만 최대 90일 보관합니다.

2. 보유 기간

주문·결제 기록은 전자상거래법에 따라 5년간 보관 후 파기합니다. 이메일 발송 목적 외 마케팅 활용은 하지 않습니다.

3. 제3자 제공·처리 위탁

  • 토스페이먼츠 — 웹사이트 결제 처리
  • Google LLC (Google Play) — Android 앱 인앱 결제 처리
  • Apple Inc. (App Store) — iOS 앱 인앱 결제 처리
  • Google Cloud — 서버·데이터 보관 (서울 리전)
  • Google (Gemini API) — 리서치 리포트 생성 (조사 주제·요구사항이 처리 목적으로 전송되며 모델 학습에 사용되지 않는 유료 API 약관 적용)

4. 이용자 권리

본인 주문 정보의 열람·정정·삭제를 요청할 수 있습니다. 문의: support@lightonpluslab.com

앱에는 계정이 없으며, 주문번호(또는 주문 시 입력한 이메일)를 알려주시면 해당 주문 데이터를 삭제해 드립니다. 이메일 발송 목적 외 마케팅 활용은 하지 않습니다.
