# 앱 이름
DeepDesk

# 간단한 설명 (80자)
주제만 적으면 AI가 출처를 교차검증해 리서치 리포트를 만들어 드립니다

# 자세한 설명
DeepDesk는 조사 주제 한 줄로 전문가급 리서치 리포트를 받아보는 앱입니다. 창업 아이템 검증, 시장 조사, 경쟁사 분석, 보고서 배경 조사처럼 며칠 걸리던 일을 몇 시간 안에 끝냅니다.

■ 이렇게 동작합니다
1. 조사 주제와 원하는 관점을 적습니다.
2. AI 리서치 에이전트가 조사 계획을 세우고, 웹 출처 수십~수백 건을 검색·교차검증합니다. 통계청(KOSIS)·전자공시(DART) 같은 공식 데이터가 있으면 우선 반영합니다.
3. 진행 상황을 앱에서 실시간으로 확인하고, 완성된 리포트를 앱과 이메일로 받습니다.

■ 리포트 구성
요약 → 핵심 지표 카드와 차트 → 상세 분석 → 실행 권고 → 참고한 출처 전체 목록. 어떤 주장이 어느 출처에서 왔는지 끝까지 추적할 수 있습니다.

■ 세 가지 분량
• 라이트: A4 7~8쪽 — 빠른 검증용
• 스탠다드: A4 10~13쪽 — 지표 카드·비교표 포함
• 딥: A4 20쪽 이상 — 차트와 전체 출처 목록 포함

■ 이런 분께
• 창업·신사업 아이템을 빠르게 검증하고 싶은 분
• 기획서·제안서·보고서의 배경 조사가 필요한 분
• 경쟁사와 시장 동향을 정리해야 하는 마케터·PM
• 과제와 논문의 선행 조사를 효율적으로 하고 싶은 학생·연구자

■ 알아두세요
• 회원가입 없이 바로 사용합니다. 리포트 전달을 위해 이메일 주소만 받습니다.
• 결제는 리포트 1건 단위이며 앱 내 구매로 처리됩니다.
• AI가 작성한 내용은 참고 자료입니다. 중요한 의사결정 전에는 출처를 직접 확인해 주세요.
• 문제가 있으면 앱의 "문제 신고" 또는 support@lightonpluslab.com 으로 알려주세요. 품질이 기대에 못 미치면 1회 무상 보완해 드립니다.
